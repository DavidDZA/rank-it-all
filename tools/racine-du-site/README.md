# daviddza.github.io

Racine du site GitHub Pages de DavidDZA. Sert surtout `/.well-known/assetlinks.json`, qui relie l'appli Android
**Rank It All** (`io.github.daviddza.rankitall`) au site https://daviddza.github.io/rank-it-all/ : sans lui,
l'appli s'ouvrirait avec une barre d'adresse. `.nojekyll` est indispensable (Jekyll ignore les dossiers en « . »).
La page d'accueil redirige vers Rank It All. Source : `tools/racine-du-site/` du dépôt rank-it-all.
